## 地球上の人類が話し扱う言語のおおよその数は？(2023年版)

地球上の人類が話し扱う言語のおおよその数は、現在**約7,100超**程度あるとされている(そう定義付けられている)。私は、この数を初めに見たとき「かなり多いな」という感想を抱いた。たぶん個人で把握しきれる数を超えていると直感したからだろう。

情報参照元は、キリスト教系の非営利研究機関・国際SILが運営・公開しているエスノローグ([Ethnologue.com](https://www.ethnologue.com/))というWebサイト。この機関は宗教観点から少数言語の保護を目的としているともされるが、多くの資料上で引用され、そのデータが具体的かつ詳細・豊富で権威性が高いと判断したため、それに基づいている。

エスノローグの公表データでは、

* 2021年: 7,139言語
* 2022年: 7,151言語
* 2023年: 7,168言語

と数える言語数が過去からわずかに増え続けている。これはもっと以前から続いていて、言語についての研究や発見による学習・分類、また言語そのもの(使用状況)が常に流動的であることによるものとの説明がエスノローグ上でもなされている。

約7,100〜という数は「現存する生きた話者がいる」自然言語が対象で、すでに話されていない*死語*は除かれている。注意点として、ラテン語は日常話者がいない死語とされるが、現在も読み書き等で限定的に使用されており、「口語としての死語」「文章語としての死語」「完全な死語」といった分類判断も必要になる。ラテン語は「口語としての死語」でおそらく除外されているだろう。

また、コンピュータ=プログラミング言語や国際補助語など人工言語(非自然言語)も自ずと除かれるはずだ。「人工言語」等については、このブログ記事シリーズの[前回Part.1](https://nova.drifting-clouds.com/blog/start-linguistics#%E4%BA%BA%E5%B7%A5%E8%A8%80%E8%AA%9E%E5%BD%A2%E5%BC%8F%E8%A8%80%E8%AA%9E%E3%82%B3%E3%83%B3%E3%83%94%E3%83%A5%E3%83%BC%E3%82%BF%E8%A8%80%E8%AA%9E)で説明している。

そしてまた、毎年どこかの国で何らかの少数言語から最後の話者がいなくなっているという事実は特筆しておくべきことだ。それらは死語化=消滅した言語として、上記の一見増加している言語のカウントをわずかにだけ減らしている。2021年2月からの1年間では4言語が実際に消滅したという。

参照: [消滅する言語と、失われていくなにか｜WIPジャパン](https://japan.wipgroup.com/media/endangered_language)

## 世界の言語話者のうち半分以上が23言語のいずれかを話している

約7,100超ある言語のうち、世界中の言語話者の半分以上は23言語のいずれかひとつを使用しているとされる。この事実については少な過ぎるとも多いとも、何とも結論し難い部分だと思うが現在の世界における言語の在り方やそのパターン・傾向を反映している、ということができるかもしれない。

| 統計項目 | データ |
| :---: | :---: |
| 世界人口 | 76.68億人(注:2023半ばで80億人突破とされる) |
| 言語 | 7,168言語 |
| 聴覚障がい者数 | 4.3億人 |
| 識字率 | 84% |

### 母語話者+第二言語話者の人口別ランキング10位まで(2023年版)

日本語で説明すると、

1.英語、2.標準中国語、3.ヒンディー語、4.スペイン語、5.フランス語、6.標準アラビア語、7.ベンガル語、8.ポルトガル語、9.ロシア語、10.ウルドゥー語...

となっている。3と7と10はインド国内で話されている言語。日本語は13位くらいで母語話者数(=人口)が割と多め。(※後に時間ができたら残り13言語も追記したい)

英語が国際共通語、もしくは異なる言語を使う人達の間で意思伝達手段としての地位を事実上築き上げていることは、近年では公然の事実になっている。世界帝国とも呼ばれたイギリス(British Empire)、初期にイギリス系移民が多かったアメリカ合衆国で事実上の公用語・母語となった結果、その影響力から英語が世界中で使われ、受け入れられる下地が整えられたと考えられる。また習得難易度がそこまで高くなく、柔軟性もあるという要因も加えられるかもしれない。

母語=第一言語だけの話者数だと標準中国語(Mandarin Chinese)が1位、英語は2位となっていて、第二言語を含めた結果と入れ替わっている。中国は世界2位14億の人口を持ち、その多くが母語・第一言語としていることから当然の結果ともいえるが、まだ歴史的に見ても国際共通語としての側面はそれほど強くない。

参考: [中国語の標準語「マンダリン」って何？ | courage-blog](https://courage-blog.com/mandarin/)

このように言語話者数の多寡は、近年の国際社会における政治・経済情勢や直近の各国人口構成からの影響をダイレクトに受けており、相関関係があるものと結論付けることができそうだ。
