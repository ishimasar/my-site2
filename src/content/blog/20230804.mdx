## 個人的に作業が捗る、お気に入りのVS Codeエディタテーマ

無料でダウンロードして使用できる軽量コードエディタ「[Visual Studio Code (略称:VS Code)](https://code.visualstudio.com/)」。もはや仕事の良き相棒として欠かせない。エディタの背景色や各種文字色、コードシンタックスハイライトの色を変更できるエディタテーマを好みで変えたり、独自カスタマイズしたりして使っているが、特にお気に入りのものを列挙したいと思う。

ちなみにコードエディタやCLIツールの使用フォントは、無料配布されているプログラミング用フォント・Ricty Diminished（リクティ・ディミニッシュト）をインストールして表示させ、15.5pxのフォントサイズで使用するのが、自分にとって最適な環境となっている。

### ダーク系テーマ7つ

実際の作業では、9割5分以上ダーク系しか使っていない。以下、使用頻度順に7つ並べてみた。後日画面キャプチャを追加予定。

1. Cobalt2
2. Winter is Coming (Dark Blue - No Italics) / (Dark Blue - No Italics)
3. Pop N' Lock Theme by Luxcium ✨
4. Vue Theme High Contrast
5. Dark+ (default dark)
6. Monokai
7. Tomorrow Night Blue 独自カスタム

使用頻度、お気に入り度は「Cobalt2」が群を抜いていて、2番目に「Winter is Coming」、3番目にほぼ同率くらいで「Pop N' Lock Theme by Luxcium」と「Vue Theme High Contrast」を切り変えて作業することが多い。気分転換的に、上記7つのエディタテーマをローテーションして使うことで作業に飽きが来にくく、集中して作業に当たることができていると感じる。

ちなみにこの記事は「Dark+」というVS Codeデフォルトのコントラスト/アクセシビリティに完全配慮されたテーマ適用で書いている。背景と文字のコントラスト比がとても高く視認しやすいのでオススメだが、人によってはコントラストが高過ぎてすぐ目が疲れ、たまに短時間で使う程度が良いかもしれない。

「Monokai」も見やすい有名テーマのひとつ。「Tomorrow Night Blue」はVS Codeデフォルトテーマで、そのままだと少し視認性に問題があり、コントラスト面でカスタマイズをして使っている。カスタマイズ方法についての記事はまた別途書くかもしれない。

### ライト系テーマ2つ

ごくまれに使用するライト系テーマも一応紹介しておく。

1. Solarized Light 独自カスタム
2. Winter is Coming (Light - No Italics)

コードを書く際やCLI(Command Line Interface)を使う際、職業病なのかライト系は基本的に眩しいという前提になってしまっているため、それほど使用していない。それでも時折ダーク系テーマ全般にも飽きがくることがあり、独自カスタムした「Solarized Light」の暖かみある配色に癒されている。

## 所感

もうここ3年くらい上記のエディタテーマ布陣で望んでいて不動かつ鉄壁な感がある。テーマ自作を試みようとしたこともあるが、今のところ既存テーマを独自カスタムするぐらいに留まっている。

最近新しいテーマも見つけたく、オススメのVS Code美麗テーマがあればどなたか教えて欲しい。
